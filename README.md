# MenuProgramacion2026

Implementaciones de estructuras de datos y algoritmos en Python y C.

## Contenido

- **Listas enlazadas** (`listas.py`, `version_c/listas.c`)
- **Pilas** (`pilas.py`, `version_c/pilas.c`)
- **Colas** (`colas.py`, `version_c/colas.c`)
- **Árboles** (`arboles.py`, `version_c/arboles.c`)
- **Búsquedas** (`busquedas.py`, `version_c/busquedas.c`)
- **Ordenamientos** (`ordenamientos.py`, `version_c/ordenamientos.c`)
- **Algoritmo de Prim** (`prim.py`, `version_c/prim.c`)

## Uso

### Python

```bash
python main.py
```

### C

```bash
gcc main.c utils.c pilas.c colas.c listas.c busquedas.c ordenamientos.c arboles.c prim.c -o menu
./menu
```

## Requisitos

- Python 3.x
- GCC (para la versión en C)
